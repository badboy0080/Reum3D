# 动画简历制作器

页面中心的 3D 动画简历工具。风格与交互参考 [intro3d.com](https://intro3d.com/)：点标签，镜头飞过去；形象全程在场，文字随页切换。

术语见 [`CONTEXT.md`](./CONTEXT.md)。

## 本地运行

```bash
npm install
npm run dev
```

打开终端提示的地址（默认 `http://127.0.0.1:5173`）。

## 已完成能力

- 选形象（Clay / Matte / Mini / Rounded）
- 分页标签 + 页间缓动运镜（预设 / X / 距离 / 高度 / 中键 / 滚轮）
- 场景背景预设、主题色、两套模板
- 文本拖拽、入场/出场目录、自定义页（最多 +4）、默认页可隐藏
- **导出单个 HTML**：可离线打开、标签翻页、镜头与文字动画（需联网加载 CDN 的 three/gsap/字体）

## 导出说明

点「导出 HTML」下载文件后，用浏览器打开即可。导出稿使用 CDN，第一次打开需要网络。
