# Character assets (形象资源)

本目录 GLB 用于编辑器预览与导出稿嵌入。许可证摘要如下（以原项目为准）：

| 文件 | 来源 | 许可 / 说明 |
|------|------|-------------|
| `chao_model.glb` | 项目自有 / 用户添加 | 自定义形象 |
| `classic.glb` | [Khronos glTF-Sample-Models · CesiumMan](https://github.com/KhronosGroup/glTF-Sample-Models/tree/master/2.0/CesiumMan) | 样本模型，可按仓库说明用于演示与产品集成 |
| `robot.glb` | [three.js examples · RobotExpressive](https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/RobotExpressive) | three.js 示例资源 |
| `soldier.glb` | [three.js examples · Soldier](https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/Soldier.glb)（原 Mixamo） | Mixamo 角色，可用于个人/商业项目成品 |
| `xbot.glb` | [three.js examples · Xbot](https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/Xbot.glb)（原 Mixamo） | 同上 |

请勿把本目录原始模型单独再分发为「素材包售卖」。随本产品导出的简历成品可一并分发。
